Journeys:

Groupings:

Sermons:

Sermon Companions:

Media Studio and Illustrations:

* Verify every visible reorder control.
* Preserve asset identity, URLs, captions, ownership and content links.

FUNCTIONAL BEHAVIOUR

For a manually ordered list:

* Up moves the selected item exactly one valid position.
* Down moves the selected item exactly one valid position.
* The first item’s Up control is disabled.
* The last item’s Down control is disabled.
* Disabled controls are visibly and accessibly disabled.
* Clicking once performs one move only.
* Rapid repeated clicks cannot create duplicate order values or corrupt the sequence.
* The interface updates immediately.
* A failed save rolls the display back and shows a clear error.
* The saved order survives:

  * Refresh
  * Route changes
  * Sign-out/sign-in
  * App/workflow restart
* Other filters such as All, Draft, Review, Published and Archived must not corrupt the complete underlying order.
* Reordering while viewing a filtered list must produce a deterministic full-list order.
* Concurrent or stale updates must not generate duplicate ordering values.
