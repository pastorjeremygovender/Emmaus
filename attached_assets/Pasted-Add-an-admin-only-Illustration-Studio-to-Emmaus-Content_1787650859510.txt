Add an admin-only Illustration Studio to Emmaus Content Studio.

IMPORTANT SAFETY INSTRUCTIONS

Before changing anything:

1. Create a restore point/checkpoint of the current working application.
2. Inspect the existing architecture, database schema, Content Studio, Walk editor, Bible Study editor, Bulk Import system, image-generation service and media storage.
3. Extend the current system. Do not rebuild or replace working features.
4. Do not change the user-facing Walk layout, completion logic, Bulk Import parsing or existing shareable-image generator.
5. Use the existing Emmaus design system, components, typography, colours, storage and authentication.
6. Only authorized administrators may generate, edit, approve, delete or publish illustrations.
7. Existing Walks and Bible Studies without illustrations must continue working exactly as they do now.

GOAL

Allow an administrator to create and insert illustrations into Walk Steps and Bible Studies.

The illustration must be generated once, reviewed and saved as a permanent media asset. It must not be regenerated whenever a user opens the content.

Support two clearly separated illustration systems:

1. Accurate Visual
2. Artistic Scene

ACCURATE VISUAL

Use controlled SVG templates and structured data for:

* Bible maps
* Timelines
* Book outlines
* Journey routes
* Teaching diagrams
* Comparisons
* People-group diagrams
* Genealogies

Do not use the normal AI image generator to create maps, timelines, diagrams, labels or geographical information.

AI-generated maps frequently contain incorrect geography, invented places and misspelled labels. All text, locations, routes and data in an Accurate Visual must come from administrator-approved structured data.

SVG visuals must:

* Render clearly on mobile and desktop
* Use the Emmaus colour palette
* Use readable text
* Support dark and light backgrounds where necessary
* Export to PNG for consistent display and sharing
* Retain the SVG source for later editing
* Include meaningful alternative text
* Contain no external hotlinked assets

ARTISTIC SCENE

Use Emmaus’s existing image-generation service for:

* Biblical landscapes
* Historical settings
* Objects and symbols
* Atmospheric scenes
* Parable illustrations
* Non-photorealistic moments from a passage

Artistic Scene rules:

* Do not place Scripture, titles, labels or other generated text inside the image.
* Do not automatically generate an identifiable face of Jesus.
* Prefer respectful environmental, symbolic, silhouette or viewed-from-behind compositions.
* Avoid modern clothing, modern buildings and historically inappropriate objects.
* Avoid fantasy imagery unless the Scripture explicitly describes a supernatural event.
* Do not generate graphic violence.
* Do not publish an image automatically.
* Every image must be reviewed and approved by an administrator.
* Reuse the existing image-generation integration and storage system where possible.

CONTENT STUDIO INTERFACE

Add an optional ILLUSTRATION section to:

* Walk Introduction
* Every Walk Step
* Walk Complete
* Bible Study content

The section must not interfere with existing fields.

Provide these actions:

* Add Illustration
* Generate Illustration
* Upload Illustration
* Replace
* Edit
* Regenerate
* Remove
* Preview
* Approve
* Unapprove

When Add Illustration is selected, ask the administrator to choose:

* Accurate Visual
* Artistic Scene
* Upload Existing Image

For Accurate Visual, provide template choices:

* Bible Map
* Timeline
* Five-Part Book Outline
* Journey Route
* Teaching Diagram
* Comparison
* People Groups
* Custom Diagram

For Artistic Scene, prefill an editable generation instruction based on:

* Bible book
* Scripture reference
* Step title
* Step reflection

The administrator must be able to edit the instruction before generating.

PLACEMENT

Allow the administrator to select where the illustration appears:

* Below Scripture
* Below Welcome
* Within Reflection
* After Reflection
* Before Consider This

If “Within Reflection” is selected, provide a paragraph-position selector rather than requiring the administrator to edit HTML.

Include optional fields for:

* Caption
* Alternative text
* Internal administrator note

Captions should be hidden when empty.

STATUS

Every illustration must have a visible status:

* Suggested
* Generating
* Draft
* Approved
* Failed

Only Approved illustrations may appear in the user-facing app.

If generation fails:

* Preserve all existing content
* Show a clear error
* Allow Retry
* Never remove or replace the previously approved illustration

BULK IMPORT INTEGRATION

Do not change the current Bulk Import syntax or parser.

After a successful Bulk Import, analyse the imported Steps and display a separate optional action:

“Suggest Illustrations”

This action must not alter the imported text.

When selected, Emmaus may suggest:

* Illustration type
* Recommended template
* Suggested placement
* Suggested caption
* Suggested alternative text
* Editable generation instruction

Do not automatically generate all suggestions.

Display the suggestions in a review list so the administrator can:

* Generate individually
* Dismiss individually
* Generate selected
* Dismiss all

Never publish suggested or generated illustrations without administrator approval.

USER-FACING DISPLAY

In the Emmaus user app:

* Show only Approved illustrations.
* Keep the content reading experience clean and uncluttered.
* Display the image at full available content width.
* Preserve its aspect ratio.
* Allow the user to tap it to view a larger version.
* Provide an accessible close button in enlarged view.
* Never open the image in a new browser tab.
* Display the caption beneath the image when one exists.
* Do not let the illustration cover Scripture, text or navigation.
* Use lazy loading to protect performance.
* Include a fixed display container or aspect ratio to prevent layout jumping.
* Use compressed WebP or AVIF for normal display, with PNG fallback where necessary.
* SVG files must be sanitised before display.

DATA AND STORAGE

Use the existing database and media-storage conventions.

Store, at minimum:

* Content type
* Content ID
* Step ID where applicable
* Illustration type
* Template type
* Source SVG where applicable
* Display image URL
* Thumbnail URL
* Generation instruction
* Structured visual data
* Caption
* Alternative text
* Placement
* Paragraph position where applicable
* Status
* Approved by
* Approved at
* Created by
* Created at
* Updated at

Use a backward-compatible migration.

Do not store generated images as temporary external URLs. Copy approved assets into Emmaus’s permanent media storage.

COST CONTROLS

Because Emmaus must remain inexpensive to operate:

* Generate each image only when an administrator explicitly requests it.
* Never generate illustrations when a user opens content.
* Never regenerate approved images automatically.
* Show a confirmation before bulk-generating selected Artistic Scenes.
* Reuse saved assets across previews.
* Prevent duplicate generation caused by double-clicks or repeated requests.
* Add request locking and idempotency.
* Display generation status while processing.

ACCURACY AND THEOLOGICAL SAFETY

Before saving an Accurate Visual:

* Validate that all labels come from the structured administrator-approved data.
* Never allow the image model to invent labels.
* Mark simplified maps clearly.
* Do not present uncertain routes as precise historical fact.
* Do not add theological claims not contained in the content.
* Do not create images of God the Father.
* Do not create sensational or irreverent depictions of Jesus, the Cross or supernatural events.
