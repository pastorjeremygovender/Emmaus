SPRINT NAME

Admin Portal Reorganisation

=====================================================

VISION

The Admin Portal should be organised around the way a church thinks and works.

Not around software features.

Administrators should immediately understand where to go without learning technical terminology.

The navigation should answer four questions:

Dashboard

"What is happening?"

Content Studio

"What are we creating?"

People

"Who are we discipling?"

Settings

"How is Emmaus configured?"

Everything else belongs naturally under one of these four areas.
