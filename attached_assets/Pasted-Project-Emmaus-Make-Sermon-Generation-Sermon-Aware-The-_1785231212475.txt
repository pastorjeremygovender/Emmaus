Project Emmaus — Make Sermon Generation Sermon-Aware

The current YouTube generation workflow is functioning correctly from a technical perspective.

It successfully:

✓ accepts a YouTube URL
✓ retrieves video metadata
✓ retrieves a transcript
✓ identifies title
✓ identifies speaker
✓ generates a sermon draft
✓ generates companion devotionals

However, the AI is currently analysing the ENTIRE CHURCH SERVICE transcript.

This is incorrect.

Emmaus does NOT generate Service Companions.

Emmaus generates Sermon Companions.

The AI must ignore:

- welcome
- notices
- announcements
- offering
- worship
- communion
- testimonies
- special items
- closing blessing

unless they are actually part of the sermon itself.

==================================================
NEW GENERATION PIPELINE
==================================================

Replace the current workflow:

YouTube URL

↓

Retrieve Transcript

↓

Generate Companion

with:

YouTube URL

↓

Retrieve Full Transcript

↓

Identify Sermon

↓

Extract Sermon Only

↓

Pastor Confirmation (if required)

↓

Generate Sermon Draft

↓

Generate Sermon Companion

==================================================
STEP 1
SERMON DETECTION
==================================================

Before any AI generation occurs, Emmaus must first analyse the transcript and identify the sermon section.

Determine:

• sermon start timestamp

• sermon end timestamp

• sermon duration

• confidence score

The detection should consider cues such as:

Beginning:

- "Let's turn in our Bibles..."

- "Today's message..."

- "This morning I want to speak..."

- "Open with me to..."

- "Our Scripture today..."

- first sustained biblical teaching

Ending:

- closing prayer after sermon

- altar call

- ministry response

- "Let's pray"

- blessing

- dismissal

The goal is NOT perfect timestamp detection.

The goal is isolating the preached message.

==================================================
STEP 2
SERMON TRANSCRIPT
==================================================

Create a new internal object:

Sermon Transcript

containing ONLY the sermon.

Do not analyse the full service transcript.

The sermon transcript becomes the ONLY source used for:

• sermon title

• Scripture

• summary

• topics

• keywords

• central truth

• key points

• companion devotionals

• future Ask Emmaus references
