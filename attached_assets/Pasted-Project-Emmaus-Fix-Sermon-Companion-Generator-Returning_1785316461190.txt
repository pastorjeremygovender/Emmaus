Project Emmaus — Fix Sermon Companion Generator Returning a Blank “Successful” Draft

Current bug:

Content Studio
→ Sermon Companions
→ New Sermon Companion
→ generate from YouTube sermon

The app navigates to the Sermon editor and displays:

“AI draft generated. Review all fields carefully…”

However, the generated fields are blank.

Visible examples:

- Title is empty;
- Speaker is empty;
- Scripture is empty;
- generated sermon analysis is missing;
- Companion content may also be missing;
- the editor is behaving as though generation succeeded.

This is a false-success state.

Fix the complete generation pipeline.

Do not redesign the Sermon Companion editor.
Do not remove the URL-first workflow.
Do not auto-publish.
Do not create another generator endpoint.
Do not display a success message unless a valid generated draft has been saved and loaded.

====================================================
PRIMARY GOAL
====================================================

After a pastor generates a Sermon Companion, Emmaus must:

1. retrieve or accept the sermon transcript;
2. isolate the sermon portion;
3. confirm the Main Theme;
4. generate valid sermon fields;
5. generate the Companion entries;
6. save the records as Draft;
7. navigate using the real saved Sermon ID;
8. load the saved values into the editor;
9. display the success banner only after the editor confirms valid data is present.

If any stage fails, remain in the generation workflow and show an accurate error or fallback.

====================================================
TASK 2 — REMOVE FALSE SUCCESS
====================================================

Find the logic that displays:

“AI draft generated.”

It must not be triggered merely because:

- the editor route opened;
- a generation request returned HTTP 200;
- a draft record exists;
- a query parameter such as generated=true is present;
- an empty Sermon record was created.

Display the banner only when all of the following are true:

- a real Sermon ID exists;
- the Sermon record was loaded successfully;
- title or an explicitly reviewable fallback value exists;
- generated analysis exists;
- the linked Companion exists;
- the expected Companion entries exist;
- generation status is complete.

Suggested condition:

generationStatus === "complete"
AND sermon.id exists
AND sermon.generatedAt exists
AND companion.id exists
AND companionEntries.length === expectedEntryCount

Do not show success for an incomplete or failed draft.
