Project Emmaus — Lock the Universal Completion Experience

This is a permanent Emmaus design standard.

The completion experience shown in the current member app (soft blue/teal completion card with centred success icon) has been approved.

We are NOT redesigning it.

We are making it the ONE universal completion component used throughout Emmaus.

==================================================
DESIGN IS LOCKED
==================================================

The existing completion card design is now the official Emmaus completion design.

Do NOT redesign it.

Do NOT replace it with a white card.

Do NOT introduce a different success screen.

Do NOT create different completion layouts for different content.

Keep exactly the same:

• soft blue/teal background
• centred green success icon
• rounded corners
• spacing
• visual hierarchy
• generous white space
• calm minimalist appearance

The visual design is approved.

Only the text and destination button may change depending on context.

==================================================
CREATE ONE SHARED COMPONENT
==================================================

Create one reusable component named something similar to:

EmmausCompletionCard

Every completion screen in Emmaus must use this component.

No page may create its own completion layout.

==================================================
USE THIS COMPONENT FOR
==================================================

• 10 Minutes with Jesus
• Daily Devotionals
• Journeys
• Sermon Companions
• Bible Studies
• Future Courses
• Any future content added to Emmaus

There must only be ONE completion component in the entire project.
