=====================================================
SPRINT

Permanent Journey Deletion (Admin Only)

=====================================================

GOAL

Emmaus currently supports Archive only.

Add a true permanent Delete option for administrators while preserving Archive as the default safe option.

This feature is primarily for development while we are creating and testing content.

=====================================================

RULES

Archive and Delete are different actions.

ARCHIVE

• Removes the Journey from members.
• Preserves all data.
• Journey can later be restored.

DELETE

• Permanently removes the Journey.
• Removes all associated data.
• Cannot be undone.
• Available ONLY to Super Administrators.

=====================================================

Super Administrator

✓ Archive

✓ Restore

✓ Delete Permanently

Content Editor

✓ Archive

✓ Restore

✗ Delete

Reviewer

✗ Delete
