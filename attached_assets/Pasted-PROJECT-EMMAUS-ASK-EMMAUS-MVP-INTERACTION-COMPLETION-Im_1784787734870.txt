CURRENT VERIFIED UX PROBLEM

After the response loads, the screen opens or remains at the bottom of the response.

The user must manually scroll upward to begin reading the response from its first sentence.

This is incorrect for the Emmaus reading experience.

PRIMARY GOAL

When a new Emmaus response begins or finishes rendering, position the viewport at the beginning of that new Emmaus response so the user can read naturally from the top.

REQUIRED SCROLL BEHAVIOUR

1. Identify the DOM element or component that represents the beginning of each Emmaus assistant response.

2. Give each assistant response a stable reference, element ID, or React ref.

3. When a response begins rendering, scroll the conversation container so that the top of the new assistant response is visible beneath the fixed Ask Emmaus header.

4. Do not scroll to the bottom of the entire conversation after the response completes.

5. Do not repeatedly force-scroll while content is streaming or expanding.

6. The user must remain able to scroll normally.

7. Once the user manually scrolls away from the response start, do not fight the user or keep resetting the position.

8. Account for the fixed header so the first line of the response is not hidden behind it.

9. Use smooth scrolling only if it does not delay or interfere with reading. Prefer reliable positioning over animation.

10. Preserve the user's submitted message above the response where practical, but prioritise making the first sentence of the Emmaus response immediately visible.
