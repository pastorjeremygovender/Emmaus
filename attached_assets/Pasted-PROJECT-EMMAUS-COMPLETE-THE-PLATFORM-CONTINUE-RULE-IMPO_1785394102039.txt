====================================================
EMMAUS PLATFORM RULE
====================================================

A user must NEVER be shown a Continue button unless a valid next item exists.

This is a global Emmaus rule.

It applies to every current and future content type.

====================================================
CONTENT TYPES
====================================================

Apply the rule to:

✓ Daily Rhythm

✓ Daily Devotionals

✓ Psalms Daily Devotional

✓ Sermon Companions

✓ Journeys

✓ Made Free

✓ Bible Reading Plans

✓ Every future sequential content type.

====================================================
RULE
====================================================

If:

nextAvailableItem exists

show:

Continue

Else:

hide Continue.

Instead show only the appropriate history link:

View Previous Days

View Previous Entries

View Previous Reflections

or equivalent.

Never attempt to navigate to an unavailable day.

====================================================
IMPLEMENTATION
====================================================

Do not duplicate this logic across multiple pages.

Create or reuse one shared helper such as:

getPrimaryAction()

or

resolveNextAction()

Every content card must use this shared resolver.

The resolver returns:

- Continue + destination

OR

- No Continue

depending on whether another valid published item exists.

====================================================
ROUTES
