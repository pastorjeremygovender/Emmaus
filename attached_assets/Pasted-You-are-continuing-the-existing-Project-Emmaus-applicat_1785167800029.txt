You are continuing the existing Project Emmaus application.

This is not a new project.

Do not redesign Content Studio.

Do not redesign the Daily Rhythm reader.

Do not change member progress, scheduling, navigation or published content.

Do not create a general-purpose chatbot.

This sprint builds a native pastoral writing assistant inside Content Studio.

=====================================================
SPRINT NAME

Emmaus Writing Assistant — Daily Rhythm

=====================================================
OBJECTIVE

Allow a pastor or authorised content editor to create and refine:

10 Minutes with Jesus

without leaving Content Studio.

The assistant must work directly inside the existing Daily Rhythm editor.

It should help the pastor move from:

Scripture reference + pastoral direction

to:

A complete editable draft.

The pastor remains the author, reviewer and publisher.

Nothing generated by the assistant may publish automatically.

=====================================================
PRODUCT ROLE

This is not Ask Emmaus.

Ask Emmaus serves members.

The Emmaus Writing Assistant serves authorised pastors and content editors.

Its purpose is limited to creating Scripture-centred discipleship content inside Content Studio.

Do not expose it to members.

=====================================================
ENTRY POINT

Inside:

Content Studio
→ Daily Rhythm
→ New Day or Edit Day

Add a clear secondary action:

Help Me Write

Use a subtle wand or writing icon if consistent with the existing design.

Do not make AI the primary action.

The pastor must still be able to write everything manually.

=====================================================
ASSISTANT PANEL

Selecting Help Me Write opens an assistant panel within Content Studio.

Use a side panel, modal or integrated workspace that fits the existing editor.

Do not navigate the pastor to an external page.

Do not open a general chat interface.

The panel should feel like a guided writing tool.

=====================================================
FIRST VERSION SCOPE

For this sprint, support only:

10 Minutes with Jesus — Daily Rhythm

Do not build specialised Journey, sermon-companion, devotional or Made Free generators yet.

The architecture may remain extensible, but the interface and testing must focus on Daily Rhythm.

=====================================================
REQUIRED INPUTS

The assistant asks for:

1. Day number

2. Day title

3. Scripture reference

4. Central truth about Jesus

Question:

What should this passage help people see about Jesus?

5. Connection to the previous day

Optional.

Question:

How should this continue from yesterday?

6. Desired next step

Optional.

Question:

What is one faithful response you would like to encourage?

7. Additional pastoral direction

Optional.

Examples:

- Suitable for someone exploring faith
- Keep it reassuring
- Avoid long paragraphs
- Focus on grace rather than guilt
- Do not repeat yesterday’s action
- Use South African English

=====================================================
SCRIPTURE VALIDATION

The Scripture reference must be validated using the existing Emmaus Bible reference parser and Bible retrieval service.

Do not allow the language model to invent Scripture text.

Before generating:

- Parse the book
- Parse the chapter
- Parse the starting verse
- Parse the ending verse
- Confirm the passage exists
- Retrieve the passage from the existing Bible system

If invalid, show:

We couldn’t find that Scripture reference.

Please check it before continuing.

Do not generate until the reference is valid.

=====================================================
SOURCE ORDER

The assistant must follow the Emmaus Constitution.

Use this source order:

1. Scripture
2. Relevant approved ICC sermon material where explicitly requested or selected
3. Emmaus synthesis

Scripture is primary.

Do not force sermon material into every Daily Rhythm entry.

For the first version, sermon search may be optional.

=====================================================
GENERATE DRAFT

Provide a button:

Create Draft

When selected, generate suggestions for:

- Greeting
- Reflection
- Prayer
- Your Next Step
- Closing

The draft should populate a review panel first.

Do not immediately overwrite the editor.

=====================================================
APPROVED DAILY STRUCTURE

The generated content must follow this structure:

Day number

Title

Greeting

Today’s Reading

Scripture loaded dynamically from the member’s selected translation

Reflection

Prayer

Your Next Step

Closing

The assistant does not generate or store the Bible passage text.

It stores only the validated Scripture reference.

=====================================================
WRITING STANDARD

Every draft must:

- Begin from the selected Scripture
- Help people see Jesus
- Sound warm, pastoral and natural
- Use clear language
- Avoid theological jargon where possible
- Avoid shame
- Avoid emotional manipulation
- Avoid guilt-based motivation
- Avoid self-help language detached from Christ
- Give one next step only
- Finish with hope
- Leave room for the reader to respond
- Sound like one person speaking gently to another
- Use natural paragraphs rather than one sentence per block

=====================================================
PARAGRAPH STANDARD

Generate prose using natural paragraph groupings.

One paragraph should normally contain one complete thought.

Most paragraphs should contain approximately two to four sentences.

Use a single-sentence paragraph only for deliberate emphasis.

Do not produce:

- A blank line after every sentence
- PowerPoint-style fragments throughout
- Large walls of text
- Artificially dramatic ellipses everywhere

The output should read naturally inside the existing member renderer.

=====================================================
GREETING RULES

Do not insert a specific person’s name.

Store a generic greeting such as:

Good morning.

I’m glad you’re here.

The member-facing renderer already personalises the first line automatically.

Do not generate:

Good morning, Jeremy.

Do not insert template variables unless the existing system requires them.

=====================================================
REFLECTION RULES

The reflection should answer:

What does this passage reveal about Jesus?

It may also explain how the passage speaks to the reader, but Jesus remains central.

Avoid turning every reflection into:

- a generic motivational talk
- a behaviour checklist
- a sermon transcript
- a full Bible commentary

The target is concise pastoral reflection suitable for approximately 10 Minutes with Jesus.

=====================================================
PRAYER RULES

Prayer should be:

- Brief
- Honest
- Christ-centred
- Connected to the passage
- Suitable for a new believer
- Natural when spoken aloud

Do not use complex theological language.

Do not promise outcomes Scripture does not promise.

=====================================================
YOUR NEXT STEP RULES

Generate one practical response only.

The next step should:

- Flow from the passage
- Be achievable today
- Encourage prayer, obedience, reflection, service or Scripture engagement
- Avoid repeating the same action used in recent days where context is available

Do not generate multiple tasks or a checklist.

=====================================================
CLOSING RULES

Default closing:

Tomorrow we’ll continue walking together.

Allow the pastor to edit it.

Do not generate:

- Congratulations
- Badges
- Streak language
- Completion celebrations
- Marketing slogans
- “Walk with Jesus” as a forced sign-off

=====================================================
CONTINUITY

Where previous Daily Rhythm days exist, allow the assistant to read:

- Previous day title
- Previous day Scripture reference
- Previous day reflection
- Previous day next step

Use this only to preserve continuity and avoid repetition.

Do not rewrite or modify previous days.

The assistant should help each day feel like part of one continuing walk.

=====================================================
REVIEW PANEL

After generation, display the proposed fields separately:

Greeting

Reflection

Prayer

Your Next Step

Closing

For each field provide:

Accept

Edit

Regenerate

Keep Existing

Do not require the pastor to accept the entire draft.

The pastor may accept one field and reject another.

=====================================================
INSERTION SAFETY

Never overwrite existing editor content silently.

If a field already contains content, show:

Replace existing content?

Options:

- Replace
- Insert Below
- Keep Existing
- Cancel

Preserve version history.

=====================================================
FOCUSED EDITING ACTIONS

Inside each existing editor field, add optional writing actions:

- Make this warmer
- Make this clearer
- Shorten this
- Improve paragraph flow
- Make this suitable for new believers
- Keep Jesus more central
- Suggest another prayer
- Suggest another next step
- Check for repetition with previous days

These actions must generate a preview suggestion.

They must not overwrite automatically.

=====================================================
THEOLOGICAL REVIEW

After generating, show a small notice:

AI-assisted draft. Please review the Scripture, theology and wording before publishing.

Provide a review summary:

Scripture used

Central truth about Jesus

Any ICC sermon source used

Warnings or uncertainties

Do not use a theology score.

Do not claim the content is theologically approved.

=====================================================
SERMON SUPPORT

Add an optional control:

Use an ICC sermon

If selected:

- Search the existing sermon archive
- Allow the pastor to choose a sermon or segment
- Preserve the real sermon ID and timestamp
- Use it as supporting context only

Do not invent sermon quotes or timestamps.

Do not copy long sermon passages.

Scripture remains primary.

=====================================================

Pastor Jeremy Style

This should use approved patterns from ICC sermons and existing Emmaus content to guide:

- Natural language
- Warm pastoral tone
- Direct application
- Hope for hurting people
- Strong focus on Jesus
- Simple explanation
- Practical next steps

Do not impersonate Pastor Jeremy.

Do not label generated words as a direct quote from him.

Do not fabricate personal stories or ministry experiences.

Provide:

Emmaus Standard

Pastor Jeremy Style

New Believer

Bible Study

Youth

For Daily Rhythm, default to:

Pastor Jeremy Style

The pastor may change it before generation.

=====================================================
STATUS AND PUBLISHING

Generated content must remain:

Draft

The assistant may never:

- Submit for review automatically
- Approve content
- Publish content
- Schedule publication
- Modify already published content without explicit editor action

The required workflow remains:

Generate

→ Review

→ Edit

→ Preview

→ Publish manually

=====================================================
USAGE PROTECTION

Prevent accidental repeated generations.

Requirements:

- Disable Create Draft while processing
- Prevent double-click duplicate requests
- Use idempotency or request tracking where practical
- Set reasonable input and output limits
- Log usage for authorised administrators

Do not expose raw token language to ordinary editors unless required.

=====================================================
ERROR HANDLING

Never show raw AI or API errors.

Use messages such as:

We couldn’t create this draft.

Your current content has been preserved. Please try again.

If Scripture retrieval fails:

We couldn’t load the selected Scripture.

Check the reference or try again.

If sermon retrieval fails:

We couldn’t load that sermon source.

Choose another sermon or continue without it.
