=====================================================
PART 1 — FIX “JOURNEY NOT FOUND”
=====================================================

CURRENT BUG

Reproduction:

Content Studio
→ Journeys
→ New Journey
→ Start from Scratch
→ Enter title
→ Create Journey

Actual result:

The app navigates to the Journey Editor, but displays:

Journey not found.

Expected result:

The Journey record is created successfully, the new Journey ID is returned, and the editor opens that exact Journey.

=====================================================
INVESTIGATION

Trace the complete creation flow.

Check:

- Form submission
- Create Journey mutation or API request
- Database insert
- Returned Journey object
- Returned Journey ID
- Route construction
- Editor query
- Cache invalidation
- Loading and error states

Determine whether:

- the database write fails
- the returned ID is undefined
- navigation occurs before creation completes
- the route uses the wrong ID field
- the editor queries a different ID format
- stale query cache causes “not found”

Do not guess.

Report the root cause after fixing it.

=====================================================
REQUIRED FIX

When Create Journey is selected:

1. Validate required fields.
2. Disable the button while creating.
3. Create the Journey record.
4. Wait for confirmed success.
5. Obtain the real persisted Journey ID.
6. Refresh or invalidate the Journey list.
7. Navigate to the editor using the persisted ID.
8. Load the newly created Journey.

If creation fails:

- Do not navigate.
- Preserve the entered form content.
- Show:

We couldn’t create this Journey. Please try again.

- Do not expose raw database errors.

Prevent duplicate records from double-clicking.

=====================================================
JOURNEY CREATION TESTS

Verify:

- A new Journey is inserted into the database.
- A valid ID is returned.
- The editor opens the correct Journey.
- The Journey appears immediately in the list.
- Refreshing the browser still loads the Journey.
- Creating two Journeys produces two unique records.
- Failed creation does not navigate.
- No duplicate Journey is created.
- No TypeScript or runtime errors remain.
