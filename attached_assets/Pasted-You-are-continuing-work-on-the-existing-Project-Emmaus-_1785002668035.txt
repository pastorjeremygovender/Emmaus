=====================================================
SPRINT NAME

AI Journey Builder

=====================================================
SPRINT GOAL

Add a guided AI-assisted creation flow inside Content Studio that can generate a complete discipleship Journey as a Draft.

A pastor or ministry leader should be able to answer a small number of clear questions and receive a structured Journey draft containing:

- Journey metadata
- Steps
- Scripture blocks
- Reflections
- Prayer prompts
- Questions where appropriate
- Action Steps
- Completion content
- Suggested related sermons where verified

The generated Journey must open in the existing Content Studio editor for review and editing.

Nothing generated by AI may be published automatically.

The required workflow is:

Create

↓

Generate Draft

↓

Review

↓

Edit

↓

Submit for Review

↓

Publish

=====================================================
PROJECT PURPOSE

Emmaus exists because we believe technology can serve a faithful purpose when it is designed and used wisely to help people walk with Jesus Christ.

Emmaus is not a general AI chatbot.

Its purpose is to help people:

- Know Jesus
- Read Scripture
- Pray
- Grow as disciples
- Participate in church
- Serve others

The order of priority is:

1. Jesus
2. Scripture
3. Discipleship
4. Church
5. Technology

Technology exists to serve discipleship, not the other way around.

=====================================================
NON-NEGOTIABLE AI CONSTITUTION

These are product rules.

They are not suggestions.

The AI Journey Builder must always:

- Treat Scripture as the primary authority.
- Search Scripture first.
- Search Pastor Jeremy Govender’s sermon archive second.
- Use AI only to weave verified sources together naturally.
- Remain discipleship-focused.
- Never replace Scripture.
- Never replace the Holy Spirit.
- Never replace the local church.
- Never pretend certainty where Scripture is silent.
- Never invent Bible verses.
- Never fabricate sermon quotations or timestamps.
- Never publish generated content automatically.
- Never become an unrestricted chatbot inside Content Studio.
- Always guide content toward practical Christian discipleship.

The default content flow should normally be:

Scripture

↓

Reflection

↓

Prayer

↓

Practical response

GENERATION BEHAVIOUR

When Generate Draft is selected:

1. Validate permissions.
2. Validate the builder fields.
3. Retrieve verified Scripture.
4. Retrieve approved sermon sources.
5. Generate the Journey structure.
6. Generate Step titles and purposes.
7. Generate blocks for each Step.
8. Save the Journey as Draft.
9. Save each Step.
10. Save each block using the existing block model.
11. Create an initial version-history entry.
12. Open the Journey in the existing Content Studio editor.

Do not generate only a large text document.

The output must populate the actual Journey, Step and Block structures.
