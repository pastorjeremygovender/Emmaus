CHECKPOINT 5 — PASTORAL DASHBOARD

This is the main Pastor Dashboard for Emmaus.

Do NOT replace the existing Dashboard.

Extend it into a true discipleship dashboard.

DESIGN GOALS

This dashboard should answer one question:

"How are our people doing spiritually?"

NOT

"How many users do we have?"

The dashboard should be clean, modern and information-rich without becoming cluttered.

LIVE UPDATES

Dashboard should refresh automatically every 30 seconds.

No page reload.

----------------------------------------------------

PERFORMANCE

Each dashboard widget loads independently.

One slow query must never block the rest.

Use separate React query hooks for every card.

----------------------------------------------------

MOBILE

Collapse sections into stacked cards.

Graphs become swipeable.

Timeline becomes accordion.

----------------------------------------------------

Do not use placeholder data if real data exists.

Use existing Care Signals, Attendance, Journey Progress, Daily Rhythm, Rooms, Sermons and Prayer Requests.

Build this as the permanent Pastor Dashboard for Emmaus.
