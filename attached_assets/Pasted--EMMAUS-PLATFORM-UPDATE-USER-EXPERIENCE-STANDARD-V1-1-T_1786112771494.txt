# EMMAUS PLATFORM UPDATE
# USER EXPERIENCE STANDARD V1.1

This update refines the Emmaus user experience.

Do NOT redesign Emmaus from scratch.

Do NOT replace working functionality.

Do NOT change database structures unless absolutely necessary.

The objective is to simplify the experience while preserving all existing progress, content and functionality.

====================================================
CORE PRINCIPLE
====================================================

Emmaus exists to help people walk with Jesus Christ.

Jesus is always the centre.

Emmaus is the companion.

The user should never feel like they are operating software.

They should feel like someone is walking with them.

Every screen should answer ONE simple question.

====================================================
BOTTOM NAVIGATION
====================================================

Bottom navigation becomes:

• Today's Steps
• My Bible
• Discover
• My Journey

Rename:

Next Steps

to

Discover

throughout the app.

Active Walks

Examples:

Prayer

Made Free

Walking with God

Continue from last position.

----------------------------------------------------

4.

Discover More

Simple button.

Opens Discover.

====================================================
VOICE
====================================================

Voice is part of Ask Emmaus.

====================================================
MEMORY
====================================================

Emmaus remembers the user's journey.

Not only conversations.

Examples.

"You completed Day 4 yesterday."

"You recently highlighted this verse."

"This week's Sermon Companion is now available."

Suggestions must always be gentle.

Never intrusive.

Never pop-ups.

====================================================
SERMONS
====================================================

Content Studio becomes the ONLY source of truth.

Only published sermons appear in the member app.

Deleted sermons disappear from member discovery.

No seeded demo sermons.

No duplicate sermon sources.

Only one sermon can be marked:

This Week's Sermon.

Today's Steps always displays that sermon.

====================================================
SERMON COMPANIONS
====================================================

Five-day companions must always generate:

Day 1

Day 2

Day 3

Day 4

Day 5

Never four.

Generator should never refer to:

"The pastor"

Instead use:

Pastor Jeremy

or

We reflected on...

or

We spoke about...

Future churches should automatically use the configured speaker name.

====================================================
CONTENT STUDIO
====================================================

Remove Media Studio completely.

Separate:

Walks

Journeys

Walks contain content.

Journeys organise Walks.

Bible Study becomes its own section.

Remove duplicate Bible Study navigation.

====================================================
ADMIN DESIGN
====================================================

Admin should feel simple.

No complicated library management.

Every content page should simply have:

Search

+ New

Recent items

Show older

Avoid unnecessary filters unless genuinely required.

====================================================
GENERAL UX RULES
====================================================

One tap whenever possible.

No unnecessary screens.

No unnecessary confirmation pages.

No duplicated navigation.

No duplicate data sources.

The user should never need to understand Emmaus' internal structure.

====================================================
SUCCESS CRITERIA
====================================================

A new believer should understand Emmaus within minutes.

Every screen should have one obvious purpose.

Ask Emmaus should feel like a companion.

Today's Steps should feel like today.

Discover should feel like exploration.

My Journey should feel personal.

The app should feel calm, simple and Christ-centred.

Before completing this update, audit every changed screen to ensure it follows these standards.
