TASK 6 — FIX API AND RESPONSE HANDLING
====================================================

Inspect the actual Bible provider response structure.

Ensure the code does not assume the wrong property names, such as:

- response.text when the provider returns response.data.content;
- response.verses when the provider returns passages;
- plain JSON when the provider returns HTML-formatted verse content;
- a single passage object when the provider returns an array.

Normalize the provider response in the shared Bible service before passing it to the UI.

Sanitize any provider-supplied HTML before rendering.
Preserve verse numbers where supported.
Do not display raw markup or API metadata.

Handle:

- 200 success
- 400 invalid reference
- 401/403 provider authentication or licensing failure
- 404 unavailable passage/version
- 429 rate limit
- network timeout
- malformed response
