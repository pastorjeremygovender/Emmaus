STEP 1 — VISUAL REASONING

Send the exact devotional quote to GPT-5.6 Sol.

Ask it to determine:

1. Emotional centre
   What is the deepest emotional/spiritual idea being communicated?

2. Visual metaphor
   Choose ONE strong visual metaphor or scene that communicates that idea visually.

The image should add meaning rather than merely decorate the words.

3. Composition
   Determine the best relationship between:

* imagery
* negative space
* typography
* focal point
* light
* visual balance

4. Text hierarchy
   Determine which part of the exact supplied quote should receive the greatest visual emphasis.

Do not automatically make the first sentence largest.

5. Mood
   Determine the emotional atmosphere appropriate to this particular devotional.

6. Avoid
   Identify obvious clichés or visual choices that would make this particular image generic.

The reasoning response should be structured data that the application can reliably parse.

For example:

{
"emotionalCentre": "...",
"visualMetaphor": "...",
"composition": "...",
"heroText": "...",
"mood": "...",
"avoid": ["...", "..."]
}

This reasoning is internal.

Do NOT display it on the generated artwork.
