PROJECT EMMAUS – REDESIGN THE JOURNEYS CONTENT STUDIO

IMPORTANT

This is an architecture improvement, not a rebuild.

Before making changes:

- Create a Git commit or Replit checkpoint.
- Preserve all existing journey, lesson, collection and database records.
- Do not rebuild the Journey Editor if one already exists.
- Reuse existing APIs, routes and components wherever possible.

====================================================
GOAL
====================================================

The Journeys section currently opens to Collections.

This is unintuitive.

Collections are an organisational feature, not the primary content.

The primary object in Emmaus is the Journey.

The Journeys section should therefore open to the Journey Library.

Collections should become a secondary organisational view.

====================================================
DESIGN PRINCIPLE
====================================================

The Emmaus administrator thinks:

"I want to create a Journey."

NOT

"I want to create a Collection."

Collections exist only to organise journeys.

Journeys are the primary content.

Design every screen around that principle.
