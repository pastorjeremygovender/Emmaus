Project Emmaus — Diagnose and Fix “We Couldn’t Generate the Sermon Draft”

Current behaviour:

Content Studio
→ Sermons
→ New Sermon
→ paste a valid YouTube URL
→ Generate Draft

The UI returns:

“We couldn’t generate the sermon draft. Please try again in a moment.”

The URL-first interface is correct. Do not redesign it.

Fix the complete generation request end to end.

Do not hide the real problem behind another generic catch block.
Do not auto-publish anything.

====================================================
PRIMARY GOAL
====================================================

A logged-in authorised pastor must be able to:

1. paste a valid public YouTube sermon URL;
2. click Generate Draft;
3. establish an authenticated server request;
4. retrieve available video metadata and transcript;
5. generate a sermon draft;
6. generate a five-day companion draft;
7. open the editable review screen.

If transcript retrieval is unavailable, the pastor must receive the approved transcript-paste fallback rather than a failed generation message.
