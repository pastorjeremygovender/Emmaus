=====================================================
BUG

The “Preached Here” feature currently returns the same sermon results for every chapter in a Bible book.

Example:

Luke 1, Luke 2, Luke 3 and other chapters may all display the same sermons because the search appears to match only the book name “Luke.”

This is incorrect.

The results must be specific to the chapter currently open.

=====================================================
EXPECTED BEHAVIOUR

When the user opens:

Luke 1

and selects:

Preached Here

show only sermon references that genuinely relate to Luke chapter 1.

Valid matches include:

- Luke 1
- Luke chapter 1
- Luke 1:1
- Luke 1:1–4
- Luke 1:26–38
- Any verse range wholly or partly within Luke 1
- Structured sermon metadata explicitly linked to Luke 1
- Indexed transcript segments explicitly associated with Luke 1

Do not include a sermon merely because it mentions the book of Luke somewhere.

Do not include sermons associated only with:

- Luke 2
- Luke 3
- Luke 4
- Luke 15
- Another chapter in Luke
- The book of Luke generally without any chapter-level reference

=====================================================
MATCHING PRIORITY

Use this matching order:

1. Exact structured chapter reference
2. Verse reference within the current chapter
3. Explicit transcript mention of the current book and chapter
4. Explicit sermon metadata associated with the current chapter
5. Broader book-level result only as an optional fallback when there are no chapter-specific results

Do not mix broad book-level matches into the main chapter-specific results.

- Starting verse
- Ending verse

=====================================================
CHAPTER MATCHING RULE

A result is chapter-specific only when the normalised reference has:

- The same Bible book as the open chapter
- The same chapter number as the open chapter

For example:

Open chapter:

Luke 1

Luke 1
Luke 1:1
Luke 1:26–38

Exclude:

Luke 2
Luke 10
Luke 11
Luke generally with no chapter reference

- Luke 10
- Luke 11
- Luke 12
- Luke 15

Use parsed numeric chapter comparison or safe reference boundaries.
