==================================================
1. TEN MINUTES WITH JESUS: RETURN AUTOMATICALLY
==================================================

Current problem:
At the bottom of Ten Minutes with Jesus, the user taps Continue, sees a separate completed-reading message, and then has to manually tap “Back to Today’s Steps.”

Required behaviour:

When the user taps Continue or completes the daily reading:

1. Save the day as completed.
2. Update all relevant progress and streak data.
3. Return the user directly to Today’s Steps.
4. Do not require a second tap.
5. Do not leave the user on an unnecessary intermediate completion screen.

The transition should feel immediate and intentional.

If a short completion confirmation is needed, show it briefly as a toast/snackbar before returning to Today’s Steps, for example:

“Today’s time with Jesus is complete.”

Do not create an additional full-page confirmation step.

2. FIX SERMON COMPANION: “JOURNEY STEP NOT FOUND”
==================================================

Current problem:
Tapping Continue on the Sermon Companion card opens a blank screen displaying:

“Journey step not found.”

This must be fixed.

Please trace the complete navigation and data-loading flow for Sermon Companion journeys.

Check and correct:

- The journey ID passed by the card
- The current day or current step ID
- Slug versus database ID mismatches
- Journey type filtering
- Published versus draft filtering
- Day-number indexing
- Route parameters
- API/database query conditions
- Any assumption that Sermon Companion uses the same data structure as another journey type

Required behaviour:

- Continue must open the correct current Sermon Companion devotional.
- Review must reopen the correct completed devotional.
- If the user has completed Day 1, Continue must open Day 2 when Day 2 is available.
- If the next day is time-locked, show the proper completion panel rather than “Journey step not found.”
- If journey data genuinely cannot be loaded, show a useful recovery screen with a button back to the correct source page.

Never expose the raw message “Journey step not found” to users.

Add safe fallback handling, but fix the underlying data and routing issue rather than only hiding the error.

4. RETURN USERS TO THE SCREEN THEY CAME FROM
==================================================

Current problem:
When Psalms Daily Devotional is opened from Next Steps, the completion link says:

“Back to Today’s Steps”

That is incorrect.

The return destination must depend on where the devotional was opened.

Required behaviour:

Opened from Today’s Steps:
- Completion button says “Back to Today’s Steps”
- Returns to Today’s Steps

Opened from Next Steps:
- Completion button says “Back to Next Steps”
- Returns to Next Steps

Opened from My Journey or another valid source:
- Return to that source screen using the appropriate wording

Implement this using an explicit source/origin parameter such as:

source=today
source=nextSteps
source=myJourney

Do not rely only on browser history, because refreshed pages and direct routes must still behave safely.

Use a sensible fallback:
- Daily rhythm and Psalms content default to Today’s Steps
- Additional journeys and Sermon Companions default to Next Steps

5. STANDARDIZE THE COMPLETION DESIGN
==================================================

Use the current Sermon Companion completion panel as the standard completion design for:

- Ten Minutes with Jesus
- Psalms Daily Devotional
- Sermon Companion
- Other multi-day journeys and devotionals

The standard panel should contain:

1. A completion check icon
2. A clear completion heading
3. A short next-day message, when another day exists
4. One outlined return button
5. No duplicate completion messages
6. No unnecessary second confirmation screen

Examples:

Ten Minutes with Jesus:

[check icon]

Day 7 complete

Come back tomorrow for Day 8.

[Back to Today’s Steps]


Psalms Daily Devotional opened from Today’s Steps:

[check icon]

Today’s devotional complete

Tomorrow’s devotional will be here tomorrow.

[Back to Today’s Steps]


Psalms Daily Devotional opened from Next Steps:

[check icon]

Today’s devotional complete

Tomorrow’s devotional will be here tomorrow.

[Back to Next Steps]


Sermon Companion:

[check icon]

Day 2 complete

Day 3 will be here tomorrow.

[Back to Next Steps]

If the journey itself is completely finished, use:

[check icon]

Journey complete

You’ve completed this journey.

[Back to Next Steps]
