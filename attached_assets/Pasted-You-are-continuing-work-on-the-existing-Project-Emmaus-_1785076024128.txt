TASK

Add Permanent Delete for Admin Content

=====================================================
CURRENT PROBLEM

Journey management currently offers Archive only.

There is no true Delete option.

Administrators need to permanently remove test content while Emmaus is still being built.

Add a visible and working permanent Delete action.

=====================================================
APPLIES TO

Add permanent deletion for:

- Journeys
- Daily Rhythm entries

Do not add deletion to unrelated systems in this sprint.

=====================================================
PERMISSIONS

Only authorised Super Administrators may permanently delete content.

Content Editors may:

- Archive
- Restore

Content Editors may not permanently delete.

Members must never see admin deletion controls.

Enforce permissions on both the interface and server.

Do not rely only on hiding the button.

=====================================================
USER INTERFACE

In Content Studio, each Journey and Daily Rhythm entry should have an actions menu.

Include:

- Preview
- Edit
- Duplicate
- Archive
- Delete Permanently

“Delete Permanently” must:

- Be visually distinct
- Use red text or a red destructive icon
- Appear only for authorised Super Administrators

Do not replace Archive.

Archive and Delete are separate actions.

=====================================================
DELETE CONFIRMATION

When “Delete Permanently” is selected, open a confirmation dialog.

For a Journey:

Title:

Delete Journey Permanently?

Message:

This will permanently delete this Journey, all of its Steps and Blocks, and all progress connected to it.

This action cannot be undone.

For a Daily Rhythm entry:

Title:

Delete Daily Rhythm Entry Permanently?

Message:

This will permanently delete this Daily Rhythm entry and any progress connected to it.

This action cannot be undone.

Require the administrator to type:

DELETE

The destructive button remains disabled until DELETE is entered exactly.

Buttons:

Cancel

Delete Permanently

Prevent double-clicking or duplicate delete requests.

The operation must be idempotent.
