--------------------------------------------------
BIBLE DATA ARCHITECTURE
--------------------------------------------------

Build the Bible Engine around a provider pattern.

The UI must never depend directly on one Bible translation.

Create a Bible Provider abstraction.

It must later support:

• Licensed Bible APIs
• Public-domain Bibles
• Offline Bible databases
• Multiple providers

Switching providers should not require UI changes.

ASK EMMAUS
--------------------------------------------------

Why did Nicodemus come at night?

3 Practical application

4 Church teaching (if available)

Never place church teaching above Scripture.
