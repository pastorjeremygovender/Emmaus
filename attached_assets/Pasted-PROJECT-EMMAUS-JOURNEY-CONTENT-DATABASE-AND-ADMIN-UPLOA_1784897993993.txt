PROJECT EMMAUS — JOURNEY CONTENT DATABASE AND ADMIN UPLOAD SYSTEM

Implement directly in the existing Project Emmaus codebase.

This is a feature-completion build.

Do not redesign unrelated user screens.
Do not replace the existing database unless it is technically unusable.
Do not build a second parallel Journey system.
Do not hard-code new Journey content in frontend components.
Do not modify Ask Emmaus, the Bible Engine, sermon retrieval, Rooms or authentication except where integration is explicitly required below.
Do not mark complete from compilation alone.
Do not propose additional features after completing this task.

==================================================
GOAL
==================================================

Create a complete database-backed Journey Content Management System inside the existing Emmaus Admin Portal.

An authorised administrator must be able to:

- create a Journey
- upload or enter Journey material
- organise it into days, chapters, lessons or steps
- add Scripture references
- add written content
- add reflection and prayer prompts
- add actions and completion requirements
- add images, audio, video and downloadable files
- preview the Journey
- save it as a draft
- publish it
- edit it later
- unpublish or archive it
- assign it to users, Rooms or church groups where current architecture supports this
- make it appear automatically in Next Steps and Today’s Steps without changing code

The user-facing app must retrieve Journey content from the database rather than from hard-coded sample objects.
