Build a new major module called Emmaus Media Studio.

This is NOT a social graphics generator.

This is a complete ministry content production studio.

The purpose of Media Studio is to allow one sermon, devotional or journey to become an entire week's worth of ministry content while preserving pastoral review before publication.

This is a major Admin Portal module.

Do not modify the user-facing Emmaus application.

Do not modify authentication.

Do not change existing journeys.

Do not alter Firestore structures unnecessarily.

Preserve all current functionality.
