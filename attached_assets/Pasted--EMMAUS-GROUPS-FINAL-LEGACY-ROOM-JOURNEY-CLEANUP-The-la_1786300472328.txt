The latest published build still contains legacy Room and personal Journey behaviour.

This must now be fixed across the entire user-facing Groups flow.

Do NOT add new features.

Do NOT redesign Groups again.

This task is a cleanup of old terminology, navigation and gating logic.

Search the entire user-facing codebase.

Replace every remaining visible reference to:

Room Members

with the correct Groups terminology:

Group
Groups
My Groups
Open Group
Create Group

- Discover

- navigation labels

====================================================

====================================================
4. REMOVE PERSONAL DAILY RHYTHM GATING FROM GROUPS
====================================================

Critical:

The Road to Emmaus page still shows:

"Complete today's 10 Minutes with Jesus"

and blocks access.

This personal Daily Rhythm requirement must NOT apply when the user entered the content through a Group.

Groups are independent of personal progression rules.

If a Group assigns:

The Road to Emmaus

the member must be able to open and prepare that study immediately, regardless of whether they completed 10 Minutes with Jesus personally.

====================================================

Do NOT globally remove the existing Daily Rhythm rule from personal discipleship if it is still intended there.

The rule is:

PERSONAL FLOW:
Existing personal Daily Rhythm gating may continue.

GROUP FLOW:
Never enforce personal Daily Rhythm gating.

The app must know the content was opened from a Group context.
