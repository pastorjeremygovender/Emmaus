---
name: Bible Study coverage queue
description: The source of truth and ordering rule for Bible Study AI generation choices.
---

Bible Study AI generation choices should derive from the canonical 66-book catalogue. Coverage status should come from the admin study statistics, with books needing work presented before books whose selected content type is complete.

**Why:** A six-book seed shortlist made the generator appear finished because it only exposed the books that had already been seeded, preventing admins from continuing coverage across the rest of Scripture.

**How to apply:** Keep the full book catalogue available, mark completed items clearly rather than hiding them, and use the selected generation type when deciding whether a book is complete.
